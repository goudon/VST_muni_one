# sample - 参考シンセ仕様まとめ

`VST_muni_one` の機能設計の参考にするため、外部シンセ (OSS) のパラメータ構成や
アーキテクチャをまとめる。本ディレクトリのドキュメントは **本プロジェクトの
仕様ではなく、参考情報** である点に注意。

## 一覧

| ファイル | 内容 |
|---------|------|
| [nyasynth.md](nyasynth.md) | [a2aaron/nyasynth](https://github.com/a2aaron/nyasynth) — Meowsynth 系シンセのパラメータ全項目とアーキテクチャ概要 |

## 用途

- `docs/parameters.md` にどのパラメータを採用するかを検討する際の比較対象。
- GUI でパーツ操作 (目・耳・眉・鼻) にどのパラメータを割り当てるかの叩き台。
- ライセンス・依存関係・実装手法を直接参照する場合は、必ずリンク先のリポジトリで
  最新の状態を確認すること (本ディレクトリは特定時点でのスナップショット)。
